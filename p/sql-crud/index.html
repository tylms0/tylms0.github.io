MySQL 的结构为：库 → 表 → 列 → 数据

一、查询（SELECT）

（这里连接小皮的 MySQL 用于演示，mysql -u root -p）

查看当前数据库

SELECT DATABASE();   -- 大小写都可以

查看所有数据库

SHOW DATABASES;

切换数据库

USE 数据库名;

比如我这里 use 了 s1 这个数据库。

列出表的内容

查表的内容

SELECT * FROM 表名;

注意这里表名要用反引号包裹。至于为什么要用反引号：

  • 普通标识符（不是保留字的表名、列名）：不用反引号，直接写就行，比如 users、orders、name、age。
  • 保留字（MySQL 自己要用到的词）：必须用反引号包起来，否则语法就乱了，比如 table、select、order、group、desc。
  • 特殊字符：如果表名里带空格、横杠、中文等，也必须用反引号，比如 `my-table`、`用户表`。

像这里，不用反引号也能查询。

条件查询（WHERE）

怎么只查看 id=2 的那条数据呢？

SELECT * FROM 表名 WHERE id = 2;

指定查询列

如果我只想看到 password 这一列：

SELECT 你要的列名 FROM 表名 WHERE id = 2;

二、增加（INSERT）

查表会了，怎么增加数据呢？

给表加数据

给 users 表加一个用户李四，30 岁：

-- 写法一：所有列必须全部覆盖，且值的顺序要和列的顺序一致
INSERT INTO 表名 VALUES (2, '李四', 30);

可以看到数据已经进去了。但这种方式列数必须一致、顺序不能乱。

所以推荐带列名的写法：

-- 写法二：显式指定列名，更安全
INSERT INTO 表名 (列1, 列2, 列3) VALUES ('值1', '值2', '值3');

效果一样的。那中间如果空了呢？只填 id 和 age：

INSERT INTO users (id, age) VALUES (3, 25);

MySQL 会自动填充 NULL。

加表

比如给 s1 库加一张 students 表：

USE s1;

CREATE TABLE students (
    id INT,
    name VARCHAR(50),
    age INT
);

加库

CREATE DATABASE 库名;

三、改（UPDATE）

比如我要把 users 表里 id=2 的那条记录的 age 改为 20：

UPDATE 表名 SET 列1='值1' WHERE 列2='值2';

-- 实际例子：
UPDATE users SET age = '20' WHERE id = '2';

可以看到 age 已经修改。

四、删（DELETE）

删除某行

DELETE FROM 表名 WHERE 列1='值1';

-- 例子：删去 users 表中 name='2' 的那一行
DELETE FROM users WHERE name='2';

删表

DROP TABLE 表名;

删库

DROP DATABASE 库名;
